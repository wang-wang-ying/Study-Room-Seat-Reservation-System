# Study-Room-Seat-Reservation-System-Java
# 校园自习室座位预约系统
基于真实校园场景设计的自习室座位预约系统，采用前后端分离架构，通过统一的管理系统界面，为管理员和学生提供不同的功能视图！

## 1、项目介绍

这是一个基于真实校园场景设计的**自习室座位预约系统**，采用前后端分离架构，通过统一的管理系统界面，为管理员和学生提供不同的功能视图。

管理员可管理自习室、座位、学生及预约记录；学生可以进行座位预约、签到、签退和取消预约，实现完整的自习室预约业务流程。

---

## 2、系统功能

* 🔐 登录认证
* 🏫 自习室管理
* 💺 座位管理
* 📅 座位预约
* ✅ 我的预约：取消预约、签到、签退
* 📋 预约记录管理
* 👨‍🎓 学生管理
* ⚙️ 系统管理：账号、角色、菜单
* 🔒 RBAC 角色权限控制

---

## 3、技术栈

**后端：**

Java 21 + Spring Boot 2.7 + MyBatis-Plus + JWT

**前端：**

Vue 3 + Element Plus + Pinia + Vite + Vue Router + ECharts

**数据库：**

MySQL 8.0

**构建工具：**

Maven 3.9

---

## 4、项目亮点

✨ **真实业务场景**
覆盖自习室、座位、预约、签到、签退等完整业务流程。

✨ **前后端分离**
Spring Boot 提供 RESTful API，Vue3 构建管理系统。

✨ **完整预约闭环**
浏览自习室 → 选择座位 → 提交预约 → 签到使用 → 签退离开。

✨ **RBAC 权限控制**
不同角色拥有不同的菜单与操作权限，实现精细化权限管理。

✨ **Java 全栈实战**
适合学习 Spring Boot、Vue3、MySQL、JWT 认证与企业级权限系统设计。

⭐ 一个结合真实业务场景的 Java 全栈实战项目，帮助开发者系统提升前后端项目开发能力。
